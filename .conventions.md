# Repository naming conventions

## Member variables

Private and protected data members use **snake_case** with a **trailing underscore** (for example `key_`, `value_`).

Public accessors and methods do not use the trailing underscore (for example `get_key()`, `get_value()`).

## Types and classes

- Class names use **snake_case** in this project (for example `chained_bucket`, `node`).
- Type aliases in `common.h` use **PascalCase** (`Key`, `Value`) as established there.

## Files

- Public headers live under `include/WelfKV/`.
- Implementation sources live under `src/` when not header-only.
